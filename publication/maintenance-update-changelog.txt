Underground Ultimate Light Rail stations now use the same maintenance base as rebalanced vanilla underground stops, without requiring the separate cost mod. Existing player-owned bundled underground stations using the previous default are adjusted once. Elevated stations now cost 20% more to build and maintain than equivalent surface stations. Existing player-owned bundled elevated stations using the old default are adjusted once. Station layouts are unchanged.
The Light Rail station and track have new artwork in the construction menu.
