# Credits en bronvermelding

Transport Fever 3 is van Urban Games. Dit prototype gebruikt de volgende originele resources bij het uitvoeren:

- ::/stations/street/small_stops/small_new.mdl en bijbehorende menuafbeeldingen.
- ::/infrastructure/street/tram/tram_new.street en gedeelde grondtexturen.
- ::/stations/shared/industry_floor_high_priority.gtex.

Het interne test_track.street_template.lua is afgeleid van street/tram/tram_new.street_template.lua in base/content/infrastructure/street.zip, met gewijzigde lane-offsets en zonder eigen bouwmenu-entry. De schema's voor de stationconstructie zijn onderzocht in de meegeleverde stationsscripts.

Geen meshes, texturen of modellen uit het spel worden meegedistribueerd. De geïnstalleerde game levert die resources. De eigen testhalte, documentatie en controles zijn gemaakt voor dit prototype van MrNickert.

edge_test.street_template.lua is also derived from Urban Games tram_new.street_template.lua, with a single forward tram lane.

mode_probe.street_template.lua uses the same Urban Games tram template basis with additional transport modes. Native rail reference resources are loaded from the game, not redistributed.

lightrail_test.street_template.lua uses the same derived Urban Games tram template as mode_probe, with a separate description and build menu entry.

lightrail_double.street_template.lua uses the same Urban Games basis and native double tram lane offsets, with the researched transport modes and a separate build menu entry.

The internal terminus references Urban Games standard 2m track and bumper models as decorative installed-game resources; no models are redistributed.

Revision 17 compact terminus uses only the shared bare single_rail model for embedded rail visuals, replacing the previous sleeper-track and bumper visuals.
