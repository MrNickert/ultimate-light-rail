# Credits

Ultimate Light Rail is maintained by MrNickert. Transport Fever 3 and the native resources used by the mod belong to Urban Games.

Stations reference installed tram tracks, platform and underpass models, the underground hall/entrance, canopies, catenary, fences, furniture and vegetation. Underground layout data and pedestrian curves are adapted from native station scripts. The public fenced track follows native tram data. Original flat rail/paving meshes and the concrete structure use native material references.

UI adapters and styles are derived from the installed Urban Games GUI sources. Source hashes are recorded in the build manifest. The package includes this derived Lua code; no native mesh, material or texture binaries are redistributed.

Illustrative menu previews were created with OpenAI image generation; they are not in-game screenshots or new 3D assets. The compact Light Rail menu icon is a vector interpretation of the side profile supplied by the user. The original reference is preserved in the repository.

A Cities Skylines 2 image served only as inspiration for the elevated station structure. No assets from that game are included.
